# All The Tests · 全网心理测试收录库

> **本测试是由 FZYZ LSY 创作的个人项目，仅作娱乐，并不能代替任何现实心理诊断和治疗，也不保证测试结果严谨准确。**

把互联网上能找到的**正式心理量表**与**娱乐性心理测试**收进一个纯静态站点：去重、分类、标注出处，并且**明确区分"能外链的"和"必须自建的"**。

- **中国大陆可访问且免费** → 只贴官方网址，不重复造轮子。
- **不可访问或不免费** → 按公开量表题本**自建可交互测试页**（题目 / 选项 / 计分 / 结果解读全部可查）。
- **受版权或施测资质限制** → 不伪造，只做说明性收录，并给出免费替代方案。

没有后端、没有账号、没有埋点。所有作答只在浏览器里完成，"我的记录"写入本机 `localStorage`。

**作者：FZYZ LSY**（个人非商业作品，欢迎提出增删建议）。

## 首次测试前的确认

用户**第一次**开始任何一个测试之前，站点会先要求确认下面这句话（逐字）：

> 本测试是由FZYZ LSY创作的个人项目，仅作娱乐，并不能代替任何现实心理诊断和治疗，也不保证测试结果严谨准确。请知晓以开始测试：

行为细节：

- 确认之前，测试页**不渲染任何题目**，外链条目也**不给出作答入口**；但**简介与「出处与使用条件」始终可读**，用户可以先了解再决定。
- 触发范围：站内可作答的条目（`builtin` / `both`）与要跳去源站作答的条目（`link`）。纯说明性条目（`ref`）没有可做的测试，不弹门。
- 有明确出口：「先不测，返回分类」。
- 确认结果记在**本机浏览器**（`localStorage` 的 `att.consent.v2`），确认过一次后不再出现；清空浏览器数据后会重新出现。
- 「我的记录」页底部有 **「重置首测确认」** 按钮，可随时让它再次出现，也列出了本机到底存了什么。
- 这段文案在 `tools/smoke.js` 里有一份**独立的硬编码副本**做逐字比对——如果 `assets/js/app.js` 里被改写，冒烟测试会立刻失败。

## 快速开始

直接用浏览器打开 `index.html` 即可（全部为普通 `<script>`，无构建、无模块、无网络请求，`file://` 下也能跑）：

```powershell
# Windows
start index.html

# 或起一个静态服务（可选）
npx --yes serve .
```

自检脚本（Node 18+，无需任何依赖）：

```powershell
node tools/verify.js   # 数据层校验：schema / 引用 / 计分分档 / 全量答题模拟
node tools/smoke.js    # 渲染冒烟测试：全部页面与结果页在迷你 DOM 上真实渲染
```

**关于作者标识：** 原图 `AuthorLogo.png` 放在项目根目录并保持原样；页面实际加载的是 `assets/img/` 下两个等比缩放副本——否则每次打开首页都要为一个小图标拉取 1.5 MB。若你要替换标识，直接覆盖 `AuthorLogo.png` 后重新生成两个副本即可（任意图片工具等比缩放到 96px 与 256px 的 PNG）。

**关于答题交互（一处曾经的真实 bug）：** 选项最初写成 `<label class="opt">` 包一个隐藏的 `<input type="radio">`。浏览器点击 label 时会派发**两个**冒泡的 `click`——一个在 label 上，一个由 label 的激活行为转发给内部 input——于是委托处理器被调用两次，自动翻页的定时器被安排两次，表现为「答完第 x 题直接跳到第 x+2 题」。现在做了两层处理：选项改用 `<button type="button" role="radio">`（一次激活只派发一个 click，且原生支持 Enter/Space），同时 `scheduleAdvance()` 在执行前 `clearTimeout` 并再次校验 `RUN.idx` 未被改动过，逐题模式下还会忽略针对「已经翻过去那一题」的迟到事件。`tools/smoke.js` 里有对应的回归用例，会显式模拟「一次激活派发两个 click」与「迟到重复事件」两种病态输入。

**关于选项分值（另一处曾经的真实 bug，也是泄露答案）：** 作答界面一度会把 `q.v`（计分用的内部映射）渲染成每个选项后面的「N 分」。这在 8 个测试上造成了实质问题：

| 测试 | `v` | 后果 |
|---|---|---|
| 认知反思测验 CRT-7 | `[0,1,0,0]` | **直接把正确答案圈出来** |
| 孤独症谱系商数 AQ-10 | `[0,0,1,1]` | 泄露哪些选项计入得分 |
| RAADS-R | `[3,2,1,0]` | 泄露计分方向 |
| 进食态度 EAT-26 | `[3,2,1,0,0,0]` | 泄露计分方向 |
| 尼古丁依赖 FTND / 酒精筛查 AUDIT | 自定义分值 | 泄露计分方向 |
| 匹兹堡睡眠质量 PSQI | 时长/分钟数 | 把内部取值当分数显示 |
| 道德基础问卷 MFQ-30 | 恒等映射 | 虽不泄露正误，仍会诱导往高分选 |

现在**作答界面一律不显示选项分值**——计分规则在结果页的「分档参照」里完整公开，不需要（也不应该）在作答前展示。`tools/smoke.js` 会遍历每个测试的每一道题，断言同一题内所有选项**结构完全对称**（除文字外没有任何区分正确项的信息）、且属性里不带数字。

作为补偿，对于**有客观正确答案**的测试（目前只有 CRT-7，通过 `revealAnswers:true` 开启），交卷后在结果页的「作答回顾」里会逐题标出 ✓ / ✗ 与正确答案。这个回顾默认折叠，且症状类量表一律不做对错判定。

**关于「分档参照」被截断（第三处曾经的真实 bug）：** 结果页的分档明细表一度对说明列调用了 `stripShort()`，把每一档的判读文本砍到 60 字加省略号。这张表的全部意义就是**把计分规则和每一档的判读完整公开**——截断等于把最有用的部分删掉，而且是在用户最需要解释自己分数的时候。

修复方式：说明列渲染完整文本，不做任何截断；同时给表格加了更适合长文本的样式（`line-height: 1.75`、说明列自然换行、当前档位高亮），并在窄屏（≤820px）把表格改成"每档一块"的堆叠布局——三列挤在手机宽度下，长说明本来也没法读。`tools/smoke.js` 会遍历每个量表、每档分数、三种作答组合，断言**每一档说明的结尾片段都完整出现**且**不带截断省略号**（当前覆盖 1260+ 行）。

## 收录规则（判定逻辑）

每条测试都有 `access` 字段，取值决定它在站点上的呈现方式：

| `access` | 含义 | 站点表现 |
|---|---|---|
| `link` | 源站中国大陆可访问 **且** 完成测试免费 | 只显示「前往源站 ↗」，不自建 |
| `builtin` | 源站不可访问、或测试不免费 | 自建答题器 + 计分 + 结果解读 |
| `both` | 源站可访问且免费，但站内也提供自建版 | 两者都给，便于离线作答与留档 |
| `ref` | 题目受版权保护 / 必须由持证人员施测 | 说明性收录：出处、获取途径、免费替代方案 |

「中国大陆可访问」与「免费」由 `assets/js/data/registry.js` 里的 `A.sources` 登记表统一维护，每个来源都带 `cn` / `free` / `zh`（是否中文界面）标记与说明文字。判定基于常规网络环境下的实际访问经验，会随地区与时间变化。

### 语言可访问性：英文外链怎么处理

这是除"能不能打开""要不要钱"之外的第三个维度——**中文用户读不读得懂**。对 26 个外链条目，逐条采取了以下三种处理之一：

1. **源站本来就是中文界面 → 保持外链**（4 条）：16Personalities 中文站、IDRlabs 中文站、SCL-90 的国内免费平台、A Real Me 中文站。
2. **源站只有英文界面，但题本公开、可以忠实翻译 → 另建中文自建版**（4 条，转为 `both`）：
   EAT-26（进食态度）、HSPS-27（高敏感）、RAADS-R（孤独症成人筛查，80 题）、CAT-Q（社交掩饰）。
   题本据英文原版逐题翻译，题量与计分规则遵循原版。这些条目在**测试页顶部、分类卡片、结果页**三处都带固定的「中译说明」。
3. **源站只有英文界面，但无法忠实自建 → 明确说明原因 + 给出站内中文替代**（18 条）。原因分四类：
   - **图形/言语推理测验**：门萨挪威版与丹麦版、123test 的智力测验——题目是标准化图形矩阵或高度依赖语言文化的言语推理，纯文本静态站点无法忠实复刻，硬做出来就是假题。
   - **商业自编题本，题目不公开**：MindTools。
   - **测验合集而非单个量表**：Open Psychometrics、SimilarMinds、Greater Good、Authentic Happiness、YourMorals——合集无法整体翻译，改为指向站内同构念的中文版。
   - **必须由受训人员施测的工具**：C-SSRS（自杀风险评估）——把它做成自动出分的自助网页既不合适也不安全。

   这些条目在页面上有专门的「英文源站」区块，逐条说明原因并列出**可以在站内用中文完成**的替代测试（共 18 条登记，全部登记的替代目标都由验证脚本校验存在且确实可作答）。

### 中译说明（重要）

凡是"由本站据英文原版翻译"的中文题本，页面上都有一条固定的告示：

> 本页中文题本由本站据公开的**英文原版题本**翻译整理，题量与计分规则遵循原版。翻译过程中，个别题目在**语义、语气或文化内涵上可能与原版存在细微差异**——也就是说，**中译版可能小部分破坏原意**。若你的结果落在临界值附近，或需要用于研究、临床等正式用途，请以英文原版为准，或对照原文再做一次。

这条告示由 `A.TRANS_NOTE`（测试页）与 `A.TRANS_NOTE_SHORT`（结果页）统一提供，标记字段是测试对象上的 `zhFrom:'en'`；分类卡片上会显示蓝色的「中译」标签。冒烟测试会逐条检查这四处提示是否都在。

**关于 RAADS-R 与 CAT-Q 的范围说明（本站主动披露）：**
- RAADS-R 只报告**总分（0–240）**，未复刻原量表的四个子量表——原版的子量表题目归属未完全公开，与其猜，不如只给能对得上的那个数。17 道反向题已按原版规则处理。
- CAT-Q 的三个子量表（补偿 / 掩饰 / 同化）题目归属按原量表公开说明整理，但本站未逐条复核原始因子载荷，子量表分数仅供应了解自己的掩饰方式，判读以总分与专业评估为准。
- HSPS 只报告总分均值——原量表本身按单一维度计分，后来研究提出的两因子与三因子模型在各研究间题目归属并不一致。

## 去重策略

`A.clusters` 里有 **18 组**判定规则，每组说明合并依据、保留了什么、为什么。核心原则：

1. **同构念只留最优版本** —— 如 PSS-14 / PSS-10 / PSS-4 只保留 10 题版；UCLA 孤独量表 20/8/3 题版只保留 20 题版。
2. **同名不同构念必须拆开** —— 「睡眠量表」其实是三种构念：睡眠质量（PSQI）、失眠严重度（ISI）、日间嗜睡（ESS）。合并会让结果自相矛盾，因此分列。
3. **输出形式不同不算重复** —— 依恋的 ECR-R（两个连续维度）与四类型速测（分类标签）信息量不同，两者都保留；但同族其余版本不再收录。
4. **版权受限的用说明性条目占位** —— 如 MBTI 官方版、韦氏智力测验、MMPI-2、16PF，不伪造题目，标注版权状态并给出免费替代。
5. **娱乐测试识别换皮** —— 娱乐类题本一律自建原创，同一构念只保留一个版本，避免"你是哪种动物"与"你的恋爱人格"共用同一套题目。

## 计分引擎支持的题型

`engine.js` 原生支持 5 种计分方式（数据里用 `score.type` 声明）：

| 类型 | 用途 | 例子 |
|---|---|---|
| `sum` | 总分 + 分档 | PHQ-9、GAD-7、Rosenberg、AUDIT |
| `mean` | 均分 + 分档 | Grit-S、SCS-SF、BRS |
| `dims` | 多维度分别计分 | DASS-21、IPIP 大五、ECN-R、RIASEC、Schwartz |
| `type` | 二分维度组合出类型码 | 四维人格类型、依恋四类型、政治光谱两轴 |
| `most` | 计次归类，取最高项 | VARK 学习偏好、爱的五种语言、聊天风格 |
| `fn` | 自定义函数 | 生活取向测验（含填充题）、PSQI（7 成分合成）、WHO-5（×4 百分制） |

其他引擎能力：

- **逐题支持独立选项与分值**（`o` / `v` / `k`），因此 AUDIT 第 2、9、10 题不同的分值方案、AQ-10 的 0/0/1/1 二元计分都能原生表达。
- **反向计分**用 `r:1`，自动按该题最大分值取补。
- **不计分题目**用 `noScore:1`（如 PHQ-9 的功能损害题、LOT-R 的填充题）。
- **危机提示**：`itemAlert` 可在特定题目被选中时（如 PHQ-9 第 9 题）触发求助信息；`ranges` 的第 4 个元素也可挂载分档级警报。
- **HTML 白名单净化**：所有富文本经 `A.safe()` 处理，仅保留排版标签，外链强制 `rel="noopener noreferrer"`。

## 如何新增一个测试

只需往任意 `assets/js/data/*.js` 里加一个对象，无需改动引擎或应用层：

```js
A.add({
  id:'my-scale',                       // 唯一 id（必填）
  cn:'我的量表', en:'My Scale',         // 中英文名（必填）
  cat:'selff',                          // registry.js 里的分类 id（必填）
  access:'builtin',                     // link | builtin | both | ref（必填）
  minutes:3,                            // 预计用时
  tags:['关键词','用于搜索'],
  creator:'作者 (年份)',                 // 原始作者
  license:'学术研究免费使用',             // 使用条件
  srcs:['spspScales'],                  // 引用 registry.js 里的来源键
  link:'https://…',                     // 可选，主源链接
  desc:'一句话简介（卡片用）',
  intro:'答题页顶部的说明，可用少量 HTML',
  stem:'这句话在多大程度上符合你？',       // 每题共通的题干
  scale:['完全不符合','比较不符合','一般','比较符合','完全符合'],

  q:[
    '普通题目，用统一选项',
    { t:'反向计分题', r:1 },
    { t:'某个维度的题', d:'DIM' },
    { t:'自定义选项的题', o:['没有','有过','经常'], v:[0,2,4] },
    { t:'不计分的附加题', noScore:1 }
  ],

  score:{ type:'sum', ranges:[
    [10,'低','分档解读文本'],
    [20,'中','…'],
    [30,'高','…', { kind:'warn', text:'可选的分档级提示' }]
  ]}
});
```
